_A Glauber Monte Carlo code for the simulation of relativistic heavy-ion collisions._

# Overview
The GlauberEvent class contains the information about the nucleus relevant to the collision—the mass number, nucleon-nucleon cross section (corresponding to a center-of-mass energy), and skin depth—and is instantiated at a singular collision event. Batches of collisions are simulated event-by-event, and the Glauber quantities (impact parameter, ncoll, npart) can be written as histograms or trees (in progress). 

Additional functions will be written to fit a Glauber simulated multiplicity to an observed multiplicity and determine centrality.
